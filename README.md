# 班級智慧排座位系統 (Classroom Seating Planner) 🪑✨

一款專為中小學及高中班級導師設計的智慧排座位網頁工具。以「視線無遮擋」為核心原則，結合「愛講話閨密隔離演算法」、「視力優先關懷」與「手動彈性微調」，並支援一鍵無損匯出與列印。

🎯 痛點與設計初衷

每逢開學或定期換座位，導師往往需要耗費數小時反覆調整，面臨多重限制：

視線被擋：高個子坐在矮個子正前方，影響後排聽課與視力。

講話干擾：要好的朋友或愛講話的學生坐太近，課堂秩序難以維持。

教室格局限制：垃圾桶旁、冷氣口正下方、柱子遮擋處或角落需要預留空位（不排人）。

特殊學生需求：近視散光、聽力障礙或需要就近關懷的學生必須坐在前排兩側。

列印排版混亂：一般網頁直接列印容易跑版、分頁斷頭或破圖。

本系統透過最佳化啟發式演算法（Simulated Annealing + 局部搜尋），在數毫秒內為全班運算出最佳排位解，並提供直覺的拖拉點擊微調。

✨ 核心特色與亮點功能

1. 👁️ 視線無遮擋演算法 (Line-of-Sight Optimization)

提供 5 段身高區間（<155cm 到 >175cm）。

同一直行嚴格落實「前低後高」，徹底杜絕高個子擋住矮個子黑板視線。

同身高層級內加入適度隨機抖動，確保每次排位都不呆板重複。

2. 🤫 閨密 / 愛講話小團體自動分離 (BFF Separation)

可自由勾選 2～5 人為一組的隔離名單（例如：上課愛傳紙條、太嗨好友）。

內建安全距離引擎（支援「九宮格完全隔離」或「十字不重疊」），排位時強制隔開；若手動調位靠太近，座位卡片會即時閃爍紅框發出警告。

3. 🚫 自訂「不安排人」保留空位

在座位表上點擊任意座位的禁制圖示，即可將該格設為不排人（如柱子、講桌旁、冷氣口）。

系統會智慧跳過這些位置，並自動計算剩餘有效座位與補足橫列。

4. 📌 特定學生「圖釘固定」與 👓「前排優先關懷」

圖釘釘選 (Pin Seat)：將特殊生或需要特定照顧的同學釘在原位，重新排位或定期輪替時保持不動。

前排關懷 (Front-row Priority)：即使身高較高，若因近視散光勾選「視力優先」，系統會強制將其排在前兩排兩側。

5. 🔄 每月定期「整排輪替平移」

支援「全班整排左移 / 右移」一秒平移輪替，在不打亂身高梯隊與閨密隔離的前提下，定期改變視角保護學生視力防斜視。

6. 🖨️ 防破圖獨立列印與匯出中心

方法 1（推薦）：一鍵產生高解析度 PNG 圖片，支援右鍵直接複製圖片貼到 Word / LINE。

方法 2（文書整合）：一鍵複製為帶格式表格，直接在 Excel 或 Word 按 Ctrl + V 貼上。

方法 3（純淨檢視）：獨立 A4 固定比例版面，支援橫向 / 直向與 70%～125% 縮放，列印 100% 不變形。

附帶「值日生 / 小老師」與「導師簽名欄」配置。

7. 🎲 課堂抽籤點人器 & 💾 瀏覽器自動記憶

內建隨機跑馬燈抽籤器，課堂提問趣味十足。

學生名單、性別身高與座位進度會自動儲存於瀏覽器 LocalStorage，重新整理網頁不遺失。
